# Telegram-бот оновлення асортименту товарів 🤖📦

Бот для автоматизації публікації оновлень асортименту в Telegram-групу або канал з двох джерел:
1. **База даних (автоматично):** фоновий моніторинг нових надходжень товарів.
2. **Адміністратори (вручну):** покрокове створення посту через зручний інтерфейс бота (FSM).

---

## 🌟 Основні можливості

- **Два режими публікації (Кнопка-перемикач):**
  - 🟢 **Автопост УВІМКНЕНО:** нові товари з бази даних миттєво публікуються в групу/канал без модерації.
  - 🔴 **Автопост ВИМКНЕНО:** перед публікацією бот надсилає всім адмінам картку товару для перевірки з кнопками: `[✅ Опублікувати в групу]` та `[❌ Відхилити]`.
- **Ручне створення посту адміном:**
  - Крок 1: Завантаження фото товару (або кнопка «Пропустити»).
  - Крок 2: Введення назви товару.
  - Крок 3: Введення опису або характеристик.
  - Крок 4: Введення ціни (або кнопка «Пропустити»).
  - Після цього генерується **попередній перегляд (Preview)** з кнопками підтвердження.
- **Підтримка декількох адміністраторів:**
  - Усі адміністратори зі списку мають доступ до керування.
  - Захист від повторних кліків (якщо один адмін уже підтвердив або відхилив пост, інші бачать сповіщення та актуальний статус).
- **Підтримка медіа:**
  - Telegram `file_id` (для завантажених фото через чат).
  - Зовнішні URL-посилання або текстові пости (якщо фото відсутнє).
- **Кнопка для швидкого тестування:**
  - «➕ Додати тестовий товар у БД» — дозволяє в один клік перевірити реакцію фонового воркера та автопостингу.

## 🚀 Швидкий запуск без Docker (локально)

### 1. Підготовка бота та групи в Telegram:
1. Відкрийте [@BotFather](https://t.me/BotFather) та створіть нового бота (`/newbot`), збережіть отриманий токен.
2. Додайте вашого бота в цільову Telegram-групу або канал та надайте йому **права адміністратора** (надсилання повідомлень та медіа).
3. Дізнайтеся свій числовий Telegram ID (наприклад, через бота [@userinfobot](https://t.me/userinfobot)).
4. Дізнайтеся ID вашої групи або каналу (наприклад, `-100...` або юзернейм `@your_channel`).

### 2. Створення файлу конфігурації:
Створіть файл `.env` на основі `.env.example`:
```env
BOT_TOKEN=ваш_токен_від_botfather
ADMIN_IDS=ваш_telegram_id,id_другого_адміна
TARGET_CHAT_ID=-1001234567890
DATABASE_URL=sqlite+aiosqlite:///bot.db
DB_CHECK_INTERVAL_SECONDS=60
```

### 3. Встановлення залежностей та запуск:
```bash
# Встановлення необхідних бібліотек
pip install -r requirements.txt

# Запуск бота
python main.py
```

Після запуску відкрийте вашого бота в особистих повідомленнях Telegram та надішліть команду `/start` або `/admin`.

## 🐳 Запуск через Docker (для сервера / VPS)

> **Примітка:** Dockerfile та docker-compose.yml уже створені та готові до використання на сервері.

```bash
# Запуск контейнера у фоновому режимі
docker compose up -d --build

# Перегляд логів роботи
docker compose logs -f
```

## 📁 Структура проєкту

```text
├── app/
│   ├── config.py             # Зчитування та валідація налаштувань з .env
│   ├── database/
│   │   ├── database.py       # Async SQLAlchemy рушій та ініціалізація
│   │   └── models.py         # Моделі: BotSettings, Product
│   ├── filters/
│   │   └── admin.py          # Перевірка прав доступу адміністраторів
│   ├── handlers/
│   │   ├── admin.py          # Меню, перемикач автопосту, список товарів
│   │   ├── manual_post.py    # Покроковий FSM-діалог створення посту
│   │   └── moderation.py     # Обробка кнопок "Опублікувати" та "Відхилити"
│   ├── keyboards/
│   │   └── admin_kb.py       # Інлайн-клавіатури (меню, прев'ю, кроки FSM)
│   ├── schedulers/
│   │   └── db_watcher.py     # Фоновий процес моніторингу оновлень у БД
│   ├── services/
│   │   ├── product_service.py   # Робота з товарами в БД
│   │   ├── publisher.py         # Форматування та надсилання постів у Telegram
│   │   └── settings_service.py  # Керування перемикачем автопостингу
│   └── states/
│       └── manual_post.py    # Стан машини станів (FSM)
├── main.py                   # Точка входу: запуск бота та планувальника
├── requirements.txt          # Бібліотеки проєкту
├── Dockerfile                # Конфігурація образу
├── docker-compose.yml        # Оркестрація контейнера
└── README.md                 # Документація проєкту
```
